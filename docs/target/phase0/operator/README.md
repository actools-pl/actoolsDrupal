## What changes between current and Phase 0 target

Phase 0 seam hardening produces no new user-visible features. For operators running the
default `community` profile, install behaviour and the CLI command surface are identical
before and after Phase 0. The changes are structural:

- The install spine iterates `PROFILE_INSTALL_STAGES` through a stage dispatcher rather
  than calling `setup_stack()` directly. Community stages run in exactly the same order.
- Profile resolution is wired into `init`, `preflight`, `doctor`, and `handoff`. The
  `community` profile resolves to the same community handlers as today.
- The operator CLI (`/usr/local/bin/actools`) is installed from `cli/actools` rather than
  generated by a heredoc inside `actools.sh`. Command behaviour is identical.
- False claims in `docs/architecture.md` and `docs/CHANGELOG.md` are corrected.

None of these changes alter what an operator running `community` sees or does.
